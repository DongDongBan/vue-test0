# 任务看板 · 验收清单

上线前逐项执行，全部通过才算完成。每条都写明了**操作**和**预期**，失败时记录现象。

## 0. 准备

1. `npm install`
2. `npm run dev`，打开终端提示的地址
3. 清空历史数据：Devtools → Application → Local Storage → 删除 `vue-kanban:board`，刷新
4. 准备 3 条任务：
   - 「写文档」：高优先级，标签 `vue, 文档`，截止日设为昨天
   - 「修复登录」：中优先级，无标签，无截止日
   - 「完成评审」：低优先级，截止日设为今天

## A. 启动与构建

- [ ] `npm run dev` 启动无报错，页面正常显示三列
- [ ] 浏览器控制台无红色报错、无 Vue warning
- [ ] `npm run build` 成功，`dist/` 生成
- [ ] `npm run preview` 后页面功能与开发模式一致

## B. 新建 / 编辑 / 删除

- [ ] 点「新建任务」，弹窗出现且光标已在标题输入框
- [ ] 标题留空直接提交：出现「请输入任务标题」，焦点回到标题框，弹窗不关闭
- [ ] 输入 81 个字符：输入框被 `maxlength` 阻止（最多 80）
- [ ] 填写合法标题、标签「a, b, a」：创建后卡片出现在**待办列顶部**，标签去重为 `a, b`
- [ ] 点卡片「编辑」：弹窗回填全部字段，标题显示「编辑任务」，按钮为「保存」
- [ ] 修改标题保存：卡片立即更新，出现「修改已保存」提示
- [ ] 点卡片「删除」：出现确认框，提示中包含任务标题，**默认焦点在「取消」**
- [ ] 点「取消」：任务仍在，数据未变
- [ ] 再次删除并确认：任务消失，出现「任务已删除」，刷新后仍不存在

## C. 拖拽

- [ ] 拖动卡片时，被拖卡片半透明，目标列边框高亮
- [ ] 在卡片上半区/下半区悬停：插入线出现在卡片上方/下方
- [ ] 拖到另一列中间松开：卡片落到该位置，提示「已移动到「进行中」」
- [ ] 同列内向下拖动：位置正确（不出现差一位）
- [ ] 拖到「已完成」：卡片标题划线、显示完成时间
- [ ] 从「已完成」拖回「待办」：划线消失，完成时间清空
- [ ] 刷新页面：列与列内顺序完全保持
- [ ] 输入搜索词后：卡片不可拖拽，副标题出现「筛选时不可拖拽」

## D. 键盘与无障碍

- [ ] 按 `Tab` 可以依次聚焦卡片，焦点环清晰可见（不是默认虚线）
- [ ] 卡片聚焦后按 `Enter`：打开编辑弹窗
- [ ] 卡片聚焦后按 `Delete`：出现删除确认
- [ ] 卡片聚焦后按 `Ctrl/⌘ + →`：卡片移到右侧相邻列末尾，**焦点跟随卡片**
- [ ] 卡片聚焦后按 `Ctrl/⌘ + ←`：移到左侧相邻列；在第一列时按左键无反应
- [ ] 卡片聚焦后按 `Ctrl/⌘ + ↑/↓`：列内换序；首/尾位置不再移动
- [ ] 打开弹窗后按 `Esc`：关闭弹窗，原数据未变
- [ ] 无输入焦点时按 `N`：打开新建弹窗
- [ ] 在标题输入框内输入含字母 `n` 的文本：不会触发新建
- [ ] 移动后 Toast 被读屏播报（可用系统读屏或 Devtools 检查 `aria-live` 区域）

## E. 搜索与筛选

- [ ] 搜索「文档」：只剩匹配卡片，三列计数同步减少
- [ ] 搜索英文 `BUG`：命中标签 `bug`（大小写不敏感）
- [ ] 勾选「高」：只剩高优先级；再勾选「中」：两者都显示
- [ ] 截止筛选选「已逾期」：只显示未完成且截止日早于今天的任务
- [ ] 截止筛选选「今天」：显示今天到期的任务（含已完成）
- [ ] 同时使用关键词 + 优先级 + 截止：结果为三者交集
- [ ] 点「清空筛选」：搜索框清空、复选框取消、下拉回到「全部」，卡片恢复
- [ ] 无既有任务但有筛选条件时：列内显示「没有匹配的任务」
- [ ] 完全无任务时：列内显示「暂无任务」

## F. 持久化与异常

- [ ] 刷新页面：任务、顺序、完成状态全部恢复
- [ ] 控制台执行 `localStorage.setItem('vue-kanban:board', '{oops')` 后刷新：页面不白屏，空看板 + 提示「本地数据读取失败，已重置为空看板」
- [ ] 把某条任务的 `status` 改成 `"archive"` 后刷新：该条被丢弃，其余保留
- [ ] 无痕窗口打开：功能可用，出现「浏览器存储不可用，本次修改不会被保存」
- [ ] 手动填满 localStorage（可选）：出现「存储空间不足，本次修改未保存」
